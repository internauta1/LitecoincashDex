# Security reporting

Do not post wallet files, seed phrases, private keys, passwords, RPC credentials,
memory dumps or unfiltered logs in GitHub issues or pull requests.

For a vulnerability, use this repository's private security advisory reporting
if the maintainer has enabled it. Otherwise contact the community through
https://litecoincash.com.br/ and request a private reporting channel before
sending sensitive details. No dedicated security email or response-time
commitment has been established for this community distribution.

Reproduce issues with synthetic fixtures or a separate wallet without funds.
Do not cancel orders, recover swaps or move funds as part of an automated
diagnostic or build job.

Supported public binary versions have not yet been established. Platform
support and release verification are tracked in `docs/publication/READINESS.md`.
